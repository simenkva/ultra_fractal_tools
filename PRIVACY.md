# Privacy

Ultra Fractal Language Support does not collect telemetry, send formula source
over the network, or contact an external service.

The extension reads open Ultra Fractal documents and local files needed for
import resolution. It processes diagnostics in a local VS Code worker and
writes status messages to the local **Ultra Fractal** output channel. The
extension stores no account data or credentials.

VS Code, your extension registry, source-control tools, and the operating
system have their own privacy practices. This statement covers only the code in
this extension.

Report a privacy concern through the
[GitHub issue tracker](https://github.com/simenkva/ultra_fractal_tools/issues).
