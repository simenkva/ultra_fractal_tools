# Support

Report bugs and feature requests in the
[GitHub issue tracker](https://github.com/simenkva/ultra_fractal_tools/issues).

For a bug, include:

- Extension and VS Code versions.
- Operating system and file extension.
- The `UF` rule identifier for a diagnostic problem.
- Steps that reproduce the behavior.
- A small, self-contained formula sample when source text matters.

Remove credentials, private source, and third-party formula code that you lack
permission to share. A reduced sample makes parser and highlighting problems
easier to reproduce.

For suspected security vulnerabilities, avoid posting exploit details in a
public issue. Contact the repository owner through the contact details on the
GitHub profile until the project adds a private reporting channel.
